# C++ L4 Proxy

A high-performance layer-4 TCP proxy and load balancer written in C++23.

The project is intended to explore:

- TCP socket programming
- Event-driven I/O
- Concurrent systems design
- Backpressure
- Memory and buffer management
- Performance profiling
- Throughput and tail-latency optimisation
- Modern infrastructure tooling

## Build

cmake -S . -B build
cmake --build build
